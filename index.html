Keunggulan Aplikasi

Fitur Utama Mapdroid

Dirancang khusus untuk menghadirkan performa rendering peta vektor kelas dunia yang fleksibel dan hemat daya.

Engine MapLibre Native

Menggunakan runtime C++/OpenGL/Vulkan MapLibre untuk rendering tile vektor super lancar pada 60 FPS tanpa jeda.

Dukungan Multi-Style

Dapat beralih secara instan antara gaya OpenFreeMap Liberty, Positron (Light), Bright, dan MapLibre Demotiles.

Pelacakan Posisi GPS

Dilengkapi tombol "Lokasi Saya" untuk mendeteksi posisi perangkat secara real-time dan orientasi kompas arah utara.

Pin & Marker Interaktif

Ketuk lama di mana saja pada peta untuk menaruh pin kustom lengkap dengan informasi koordinat latitude dan longitude.

Auto Tag & Release CI/CD

Setiap push ke branch main otomatis menjalankan GitHub Actions workflow untuk mengkompilasi APK dan membuat GitHub Release baru.

Bebas Biaya Lisensi & API Key

100% open-source. Menggunakan protokol OpenStreetMap dan OpenFreeMap tanpa batasan kuota berbayar atau registrasi kartu kredit.

Petunjuk Penggunaan

Panduan Instalasi & Penggunaan

Langkah mudah mengunduh, memasang, dan menjalankan aplikasi Mapdroid di HP Android Anda.

1

Unduh Berkas APK

Klik tombol "Unduh APK" di halaman ini atau unduh langsung dari tab GitHub Release. File akan tersimpan di folder Download.

Berkas: mapdroid.apk
2

Izinkan Sumber Tidak Dikenal

Buka file APK. Jika Android memunculkan peringatan keamanan, buka Pengaturan dan aktifkan "Izinkan instalasi dari sumber ini" (Install Unknown Apps).

Standar instalasi manual APK Android
3

Pasang (Install) Aplikasi

Tekan tombol "Pasang" (Install) dan tunggu proses hingga selesai. Setelah itu, tekan "Buka".

Signed dengan Android keystore
4

Mulai Eksplorasi Peta

Berikan izin akses lokasi GPS jika diminta. Gunakan tombol gaya peta untuk mengganti tampilan, tombol kompas untuk arah Utara, dan ketuk lama untuk menaruh pin.

Siap digunakan!

Dokumentasi Teknis

Panduan Pengembang & CI/CD

Arsitektur proyek, otomatisasi build GitHub Actions, dan cara kompilasi APK secara lokal.

GitHub Actions Workflow

Alur kerja otomatis tersimpan di .github/workflows/release.yml. Setiap kali branch main menerima push, proses berikut berjalan:

  1. Checkout repo dengan seluruh commit history.
  2. Setup Java JDK 17 (Eclipse Temurin) & Android SDK.
  3. Setup Gradle 8.7 & membuat Gradle Wrapper otomatis jika belum ada.
  4. Build Release APK menggunakan ./gradlew assembleRelease.
  5. Auto-Tag format v1.0.<run_number>.
  6. Create GitHub Release dan unggah mapdroid.apk untuk langsung diunduh.

Perintah Kompilasi Lokal

Anda dapat mengkompilasi APK langsung di komputer lokal menggunakan Gradle Wrapper:

# Linux / macOS
./gradlew assembleRelease
# Windows PowerShell / CMD
.\gradlew.bat assembleRelease
Lokasi output APK: app/build/outputs/apk/release/app-release.apk
